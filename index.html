WhatsApp

Cómo se conecta el número

Tu número de WhatsApp Business se conecta a través de Meta (Facebook Developers). Tú creas la app y el número; TechGuard es el webhook: la dirección donde Meta entrega los mensajes para que el bot de tu empresa responda.

  1. Crea tu app en Meta En My Apps crea una app, agrega el producto WhatsApp y vincula el número. Guía: Get started · Cloud API.
  2. Copia los datos del número En WhatsApp → API Setup o WhatsApp Manager: Phone Number ID, WABA ID, App ID, App Secret. Token permanente desde System Users. Docs números: Business phone numbers.
  3. Pégalos en tu panel TechGuard En el dashboard de empresa (o TechGuard si tu plan lo incluye) guardas esos datos de forma segura.
  4. Activa el webhook de TechGuard En Meta: WhatsApp → Configuration (Set up webhooks). Pegas la URL de webhook de TechGuard y el Verify Token. Ahí Meta enviará cada mensaje entrante.

Enlaces rápidos: Get started · My Apps · Business Suite · System Users · Webhooks

Precios Meta WhatsApp (oficial): consulta el rate card por país y categoría (marketing, utility, auth, servicio) en developers.facebook.com/docs/whatsapp/pricing · Business Messaging · Pricing · actualizaciones Updates to pricing (incluye COP y cambios oct 2026).

¿Qué es TechGuard en este flujo? No es tu número de WhatsApp. Es el servidor que recibe los mensajes (webhook) y ejecuta el agente IA de tu empresa (skills, flujos, MCP) para contestar. Tú decides el contenido; Meta lleva el mensaje; TechGuard lo procesa.

Empresa

Skill · LSP · MCP del negocio

Son el contexto que tu empresa provee para que la IA responda con tu operación (no con respuestas genéricas).

Skills

El “saber” del bot: menú, precios, FAQs, políticas y tonos en markdown. Es lo que la IA lee para contestar como tu marca.

LSP

Language Server Protocol de conversación: valida el flujo (slots faltantes, intents rotos) para que el bot no improvise pasos incompletos al atender al cliente.

MCP

Model Context Protocol: conecta datos vivos (pedidos, citas, facturas, CRM, BD) para que las respuestas usen información real de tu negocio, no solo texto fijo.

En corto: tú aportas el contexto (skills + LSP + MCP); el LLM usa ese contexto para responder; TechGuard orquesta el webhook y el agente.
